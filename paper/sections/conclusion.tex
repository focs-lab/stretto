\section{Limitations and Conclusion}
\label{sec:conclusion}

\paragraph{Limitations.} The model covers point-to-point communication, probes,
completion calls and collectives by shape. RMA, neighbourhood collectives, partitioned
communication and memory accesses are outside it. Buffer reuse before a nonblocking
operation completes is reported only when the run does it, by the optional guard.
Under \texttt{MPI\_THREAD\_MULTIPLE} we report observed findings only. Skeletons are
written by hand. Our experiments use one node.

\paragraph{Conclusion.} One recorded run of an MPI program determines more than the run itself.
Over the horizon, the part of the trace every consistent program repeats, an alternative
matching is feasible iff a constraint graph with match nodes is acyclic; the check is exact
relative to the horizon. Each certificate comes with its buffering thresholds, a level for its
consequence, and a pin that forces it. On benchmarks, \tool finds \nMBItpunion of \nMBIerrors
labelled errors with no false positive; from one clean run it predicts a production race in
HYPRE that testing missed and a documented bug in NPB MG.
