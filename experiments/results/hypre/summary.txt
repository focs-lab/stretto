Analysis (report4.txt, report4-211.txt): 25 and 24 probe alternatives, all class probe-alt (a

rank 1's 400-byte pruned-rows request, feasible for B >= 3444; the other tag-222 alternatives

probes use tag 221 and only the same-shape alternatives remain.

An earlier trace of the same configuration (not committed; its pins differ, since probe ordinals

so that the neighbour can move on to the stored-rows exchange while this rank still probes.
